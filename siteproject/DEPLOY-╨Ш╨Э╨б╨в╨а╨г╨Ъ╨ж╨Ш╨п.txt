КАК ОПУБЛИКОВАТЬ САЙТ В ИНТЕРНЕТЕ

Этот проект подготовлен для статического размещения: страницы и уроки будут работать без базы данных и серверной настройки. Прогресс и настройки темы сохраняются в браузере посетителя.

САМЫЙ ПРОСТОЙ СПОСОБ — VERCEL
1. Зайди на https://github.com и создай репозиторий (New repository).
2. Распакуй этот архив на компьютере.
3. Загрузи в репозиторий все файлы и папки проекта (не сам ZIP).
4. Зайди на https://vercel.com и выбери Sign Up / Continue with GitHub.
5. Нажми Add New → Project и импортируй свой GitHub-репозиторий.
6. Нажми Deploy. Vercel сам определит Next.js и соберёт сайт.
7. После завершения появится публичная ссылка вида https://название-проекта.vercel.app — её можно отправлять кому угодно.

ВАЖНО
- Не загружай папку node_modules, если она появится.
- Для будущих обновлений достаточно загрузить изменения в GitHub — Vercel автоматически пересоберёт сайт.
- Это статическая версия: обучение, уроки, тесты и локальный прогресс доступны посетителям; общий аккаунт/синхронизация прогресса между устройствами не предусмотрены.
